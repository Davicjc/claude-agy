---
description: Mostra os modelos disponíveis no agy e qual a skill escolhe para cada papel
disable-model-invocation: true
---

Carregue a skill `agy` deste plugin para saber a pasta dos scripts e rode `<pasta da skill>/scripts/agy-modelo --listar --atualizar`.

Mostre a tabela "Escolha por papel" e a lista de modelos disponíveis. Diga em uma linha como forçar um modelo (`AGY_MODELO_<PAPEL>=<id>`, ou `AGY_MODELO=<id>` para todos). Se o comando falhar, diga que o agy precisa estar instalado e logado.
